Agent Swarm Research System

Autonomous Multi-Agent Web Research & Reporting

Overview

This application deploys a "swarm" of autonomous AI agents to conduct extensive research on advanced topics. It leverages a custom Web Crawler tool capable of navigating the open web and the dark web (via Tor), ensuring comprehensive data collection.

Workflow Stages:

  1. Brainstorming: An agent autonomously generates 100 unique research topics.
  2. Research Swarm: 100 agents run in parallel (or batched) to search (SerpAPI) and crawl (Web Crawler) for information.
  3. Synthesis: Findings are grouped into batches of 10 and summarized by intermediate "Section Compiler" agents.
  4. Reporting: A "Final Compiler" agent aggregates all sections into a detailed 5-25 page report with citations.

Prerequisites

  • n8n Instance: Running the latest version with this custom build (including ToolWebCrawler).
  • OpenAI API Key: For the GPT-4 agents.
  • SerpAPI Key: For Google Search capabilities.
  • (Optional) Tor Proxy: If you intend to crawl .onion sites or need anonymity.

Setup Guide

1. Import the Workflow

The workflow file is located at: packages/@n8n/nodes-langchain/workflows/Agent_Swarm_Report.json.

  1. Open your n8n Editor.
  2. Go to Workflows > Import from File.
  3. Select the JSON file mentioned above.

2. Configure Credentials

You need to set up credentials for the agents to work:

  • OpenAI: Open the "OpenAI Chat Model" node and select/create your OpenAI credentials.
  • SerpAPI: Open the "SerpAPI" node and enter your API key.

3. Configure the Crawler (Dark Web Support)

The Web Crawler node allows you to specify a proxy.

For Dark Web Access: Ensure you have a Tor SOCKS5 proxy running locally (usually on port 9050).
  1. Open the Web Crawler node settings.
  2. In the Proxy URL field, enter your SOCKS5 proxy:
    socks5://127.0.0.1:9050 (Adjust IP/Port if needed).
  3. Set Max Pages per Crawl (Default: 5). Increase this for deeper research, but be more mindful of execution time.

Running the Research

Click Execute Workflow. The process follows this timeline:

  • 0-1 min: Brainstorming Agent generates 100 topics.
  • 1-10 mins: The Research Swarm activates. You will see execution indicators for the "Research Agent". It uses Search to find URLs and the Crawler to read them.
  • 10-12 mins: The "Section Compiler" agents summarize the findings.
  • Final: The "Final Compiler" outputs the complete report.
Resource Warning: Running 100 GPT-4 agents can be token-intensive and costly. Ensure your API limits are sufficient.

Troubleshooting

  • Crawler Timeout: If the crawler hangs, reduce "Max Pages per Crawl" or check your proxy connection.
  • Proxy Errors: If using SOCKS5, ensure the protocol is specified as socks5://.
  • Rate Limits: If OpenAI or SerpAPI rate limits are hit, n8n may pause or fail. Consider adding "Wait" nodes or reducing the swarm size (edit the "Brainstorm Agent" prompt to ask for fewer topics).
